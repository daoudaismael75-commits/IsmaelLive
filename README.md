# IsmaelLive V1.9

Simulateur privé : audience, réactions et cadeaux fictifs, sans diffusion publique.

- Caméra entière sans zoom CSS, fond périphérique flou avec raccord adouci, sélection d'objectif si Android la permet.
- Mode plein écran par action directe ou installation PWA dans Chrome. Les navigateurs intégrés peuvent refuser le plein écran.
- Portraits synthétiques facultatifs téléchargés via install_avatars.py, avatars illustrés intégrés en secours.
- Grok : test textuel séparé avant le live, statut, latence, analyse des paroles et images sous consentement distinct.
- Compteur progressif avec fluctuations et plafond de 34,5 K.

Voir README_ONLINE.md pour Render. Ne jamais publier de clé ou de mot de passe.
